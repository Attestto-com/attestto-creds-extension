# Security Policy

## Reporting a vulnerability

Report security issues to **security@attestto.com**.

Please do not open a public issue for a security problem. If the report contains
anything sensitive, encrypt it — see our CSIRT profile for the current key and
contact details:

https://github.com/Attestto-com/security-incidents

We acknowledge reports by a human, not an autoresponder.

## Scope

This repository only. For infrastructure we operate, or for an incident rather
than a product defect, use the same address and say so.

## Disclosure

Resolved incidents affecting our own systems are published in our public
incident register. This is a standing commitment, not a case-by-case decision.
